# Deepak Karki — Portfolio

Personal portfolio built with **React + JavaScript** and **Vite**.

## Tech Stack

- React 19 + JavaScript
- Vite
- GSAP + ScrollTrigger
- Locomotive Scroll (smooth scrolling on desktop)
- Bootstrap 5 (grid/layout utilities)

## Getting Started

```bash
npm install
npm run dev
```

## Project Structure

```
src/
  components/     # All UI components
  data/           # Static content
  hooks/          # Animations & cursor
  styles/         # Global CSS
  App.jsx
  main.jsx
public/
  assets/         # Images, fonts, icons, CV
```

## Scripts

| Command           | Description                 |
| ----------------- | --------------------------- |
| `npm run dev`     | Start development server    |
| `npm run build`   | Production build to `dist/` |
| `npm run preview` | Preview production build    |
